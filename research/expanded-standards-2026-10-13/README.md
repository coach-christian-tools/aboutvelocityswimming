## Withheld and unavailable

These editions are **not staged**. A malformed value is never guessed or normalized into a different time.

- **2026 Winter Juniors:** the official Bonus table prints men's LCM 400 free as `4:37.09`, equal to the SCY 500 cut, and substantially slower than the qualifying `4:04.99`. A local extraction is retained, but the edition awaits clarification.
- **2026 Junior Nationals:** the 200 relays qualify with 400 relay performances. The current exact-event cut model cannot faithfully express this alternate-event rule. The local draft explicitly labels these entries `Qualifying (400 relay time)`; it is not import-ready.
- **2027 Summer Western Sectionals:** men's SCM 100 fly is printed `58:61`; other summer rows use nonstandard minute punctuation. Spring is a separate complete table and was staged independently.
- **2026 Western SCY Senior Zones:** women's LCM 50 breast is printed `39:59`. The whole edition is withheld rather than silently changing it to `39.59`.
- **2026 Northwest Age Group Regionals:** the SCM table labels distance freestyle rows `500 Free` and `1650 Free`, where the corresponding metric events would normally differ. No event distance is changed by inference. The complete official meet packet is retained for clarification.
- **2027 Northwest Age Group Regionals and Inland Empire championships:** no linked standards were available on the official sources checked. The Inland Empire time-standards hub has blank 2027 championship cells. The 2026 regional packet is not relabeled 2027.
- **2026 Pro Swim Series:** retained as a source capture, but the published 2027 editions supersede it for this collection.
- **2024–2028 age-group motivational:** already published; not duplicated.

The P3 disability source has a genuinely blank boys' 11–12 LCM 100 free B cell on page 5. Every published P3 value is included; the blank remains absent and is flagged in the batch's gaps. Selecting it displays “—”. This is a source omission, not a partial extraction.

## Evidence and interpretation

`sources.json` records official URLs, capture dates, and PDF SHA-256 hashes. PDFs, extracted text, and selected rendered pages are retained here. `prepared/*.evidence.json` includes a row-level trail for every cut; batch evidence contains coverage, notes, sample rows, and the full evidence file's hash. `staged-receipts.json` records exact batch IDs. `batches/` contains the staged payloads with explicit null baselines for these new editions.

- All supported source courses, genders, age groups and tiers are retained. No missing cut is converted or generated. Relay distance is stored as total distance, e.g. 4×100 = 400.
- Open-water records are explicitly **pool qualifying times**; tiers name the open-water race. AQUA ages are age on December 31, 2027. They are not open-water performance standards.
- Single-age and disability sets carry `standardType` so they do not displace the general age-group motivational benchmark. The narrow database safeguard was tested locally and applied remotely; frontend defaults and legacy selection use the same distinction.
- Source decimal comma `34,29` in Western Senior Zones is normalized to `34.29`; no numeric value changes.
- Library dates start at a stated qualification start when supplied, otherwise the capture date. Meet editions end on the final meet day; 2026 national sectional maximums use the edition's calendar-year end. Multi-year swimming editions use the season end, August 31, of their final year. These library bounds are not entry deadlines; source-specific qualification rules remain in the official documents and evidence.
- Western Age Group's hub uses a multi-year link label, but the PDF explicitly says 2026. The record follows the PDF.

## Repeat preparation and staging

Use Node 24 and Python with `pdfplumber`. Source captures are fixed; new source revisions require another capture and review, not changing an old batch in place.

```sh
python3 scripts/collection/extract-expanded-standards.py
node scripts/collection/prepare-expanded-standards.mjs
node --env-file=.env.collection.local scripts/collection/stage.mjs research/expanded-standards-2026-10-13/batches/EDITION_ID.json
```

The first command reproduces local records from captured text plus the two reviewed raster transcriptions. The second prepares only manifest entries marked `prepared`, fetching a fresh baseline through the existing public read path and validating records. Run the last command once per desired batch. It uses the scoped collector token and never approves. Identical batches are idempotent; do not change capture timestamps to bypass duplicate detection. Approve, hold, or decline through `/tools/review`.

Verified: source hashes, coverage counts, row evidence against every prepared cut, shared record validation, 2 MB batch limits, default-selection tests, unauthorized/stale/duplicate staging and publication tests, typecheck, and targeted lint. All 11 Times database integration tests and the production build also passed; production traces exclude private local data.
